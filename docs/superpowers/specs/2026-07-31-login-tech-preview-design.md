# 动态科技风登录页预览设计

## 目标

将现有白色毛玻璃登录页替换为“深空控制台”风格的真实登录页面，并在本地提供桌面和移动端预览。登录接口、登录成功后的跳转和 Token 保存方式保持不变。

## 三方案本地对比

- 普通 `/login` 默认使用“深夜控制台”，不显示预览控件。
- 本地 `/login?preview=1` 显示三方案切换器，可比较“深夜控制台”“量子导航舱”和“极光作业台”。
- 三套方案共用同一登录表单、校验、请求、Token 保存和跳转逻辑，只改变标题文案、强调色、面板材质与 Canvas 背景轨迹。
- 切换方案时同步更新地址中的 `theme` 参数，刷新页面后仍停留在当前方案。
- 量子导航舱使用冷蓝航线、椭圆轨道与琥珀操作色；极光作业台使用绿色波形、斜向遥测纹理与珊瑚操作色；深夜控制台保留青色透视网格。

## 视觉方向

- 使用石墨黑背景、冷白文字和电光青主强调色。
- 删除旧登录背景图片的页面引用，不使用通用紫色渐变、装饰性光球或图片背景。
- 全屏背景由 Canvas 绘制低密度透视网格、连接节点和扫描脉冲，动效表达系统启动与安全连接状态。
- 桌面端采用非对称布局：左侧品牌与系统视觉区域，右侧登录面板。
- 登录面板使用深色半透明材质、细边框和内侧高光，不使用白色毛玻璃。
- 移动端隐藏非必要品牌说明，将登录面板居中显示。

## 交互

- 用户名和密码使用固定可见标签，不用占位文字代替标签。
- 支持 Enter 提交、浏览器账号密码自动填充、密码显隐和清空输入。
- 登录过程中按钮进入加载状态，防止重复提交。
- 重置操作在登录请求期间禁用。
- Canvas 动效在组件卸载时释放，并遵守 `prefers-reduced-motion`。

## 技术方案

- 保持 Vue 3、Arco Design 和现有图标体系。
- 动效使用原生 Canvas 2D 与 CSS，不新增第三方动画或 3D 依赖。
- Canvas 只负责背景绘制，登录表单保持普通 DOM，确保键盘、自动填充和可访问性正常。
- 使用 `100dvh` 和明确的桌面、平板、移动断点，避免移动浏览器地址栏造成跳动。

## 验收

- 页面不再引用 `login-bg.png` 或 `login-bg2.png`。
- 1440x1000 与 390x844 视口均无横向滚动、文字裁切和控件重叠。
- 登录框、输入框、按钮、提示与 Logo 在深色主题中对比清晰。
- Canvas 非空且持续绘制，降低动态效果设置下保持完整静态构图。
- 前端生产构建通过，控制台没有页面错误。
- 登录请求、Token 保存和重定向逻辑保持原功能。

## 动效样品与最终选择

- 背景叠加四条低透明度、持续循环的运维字幕流，不影响登录表单可读性；字幕内容使用运行状态、角色、邮件、公会、PVF 和资源监控等实际后台领域词汇。
- 鼠标在桌面端移动时显示细线扫描准星，登录面板仅做轻微 3D 视差倾斜；触屏和 `prefers-reduced-motion` 环境取消该效果。
- 本地 `/login?preview=1` 增加场景样品切换，保留四种 Canvas 方案：星空连线、数据雨、引力井、波浪扫描。选择同步写入 `effect` 查询参数，刷新后保持。
- 正式 `/login` 默认采用“极光作业台 + 数据雨”。数据雨叠加在极光作业台原有的绿色波形扫描与横向扫描脉冲之上，不替换主题基础动效；预览切换控件不出现在正式登录页面。
- 场景样品参考 [likepoems 的 Web special effects 集合](https://stackblitz.com/@likepoems/collections/web-special-effects)中可见的星空连线、颗粒、黑洞和波浪方向，但使用本项目原生 Canvas 与 CSS 独立实现，不引入额外依赖。
