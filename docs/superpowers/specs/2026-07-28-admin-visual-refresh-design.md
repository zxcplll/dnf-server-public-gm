# DNF Admin 视觉改造设计

**状态：** 已确认

**目标：** 在不改变既有路由、接口、权限和业务操作的前提下，将 GM 后台统一为深夜控制室视觉，并消除桌面、移动端及浮层的遮挡问题。

## 设计判断

这是一个供 GM 重复操作的游戏服务器运维后台，不是营销页。界面需要让管理员快速扫描在线状态、玩家列表、奖励结果和错误提示，因此视觉重点是信息层级、稳定的空间尺寸和明确的状态色。

## 视觉基线

- **底色：** 深海墨色 `#080d16`，内容区使用分层蓝黑色面板，避免整页纯黑。
- **主信号色：** 青绿色，用于在线、成功、选中和主要数据变化。
- **告警色：** 琥珀色，用于注意提示、风险操作和需要复核的状态。
- **操作色：** 冷蓝色，用于按钮、链接和焦点态。
- **文字：** 主文字使用高对比冷白，辅助文字使用蓝灰；数字和状态保持清晰，不使用装饰性渐变。
- **几何：** 卡片和控件圆角不超过 8px，采用细边框和轻阴影；页面分区保持平面，不在卡片内套卡片。
- **动效：** 仅保留导航收缩、弹层进入和状态更新的短过渡；尊重 `prefers-reduced-motion`。

## 公共壳层

`webui2/src/views/admin/Index.vue` 继续作为唯一后台布局入口：

1. 侧栏保留原菜单和折叠行为，统一图标尺寸、选中条、分组间距与滚动轨道。
2. 顶栏保留用户区、面包屑和历史页签，但页签区域设置明确的最小宽度和横向滚动，避免挤压内容。
3. 内容区使用 `100dvh`、`min-width: 0` 和单一滚动容器，避免嵌套滚动条造成表格或弹窗被裁剪。
4. 视口宽度较小时，侧栏转换为抽屉层；打开抽屉时提供遮罩，关闭后恢复原滚动位置。

## 页面内容

`webui2/src/style.css` 提供全局颜色变量、字体、页面背景、按钮焦点和滚动条基线。首页 `Dashboard.vue` 使用相同变量重排欢迎区、统计块、在线列表和服务器信息，保留原请求与 10 秒轮询。

表格页、监控页、奖励页、邮件页、PVF 页和数据库页只调整容器、间距、表头、空状态和响应式规则；所有字段、分页、查询、上传、发放和删除动作保持不变。

## 浮层和子窗口规则

- 使用明确的层级令牌：基础内容 `0`、导航遮罩 `1000`、抽屉 `1100`、弹窗 `1200`、提示与物品详情 `1300`、全局通知 `1400`。
- 物品选择器和详情提示以视口为边界计算位置，超出右、下边界时翻转或收缩；宽度不超过 `calc(100vw - 24px)`，高度不超过 `calc(100dvh - 24px)`。
- 弹窗正文允许内部滚动，外层页面不跟随滚动；窄屏下弹窗改为底部抽屉或接近全屏的面板。
- 所有浮层提供可见焦点态、关闭按钮和 `Escape` 关闭，不遮挡固定顶栏的关键操作。

## 验收标准

1. `npm run build` 通过，既有 Java 后端测试继续通过。
2. 1440x900、1280x800、390x844 三个视口无横向溢出、标题截断或固定层重叠。
3. 首页、服务器监控、玩家角色/账号、奖励发放、邮件查询、PVF 管理至少各打开一次；网络请求和分页行为不变。
4. 物品选择器打开、搜索、悬停详情、滚动和关闭流程可用；详情提示在四个角落都完整显示。
5. 监控数字更新时页面壳层不闪烁，DOM 不被整页重建；减少动态效果设置下没有持续动画。
6. 浏览器控制台没有新增错误，截图中没有内容区、抽屉、弹窗或提示之间的遮挡。
